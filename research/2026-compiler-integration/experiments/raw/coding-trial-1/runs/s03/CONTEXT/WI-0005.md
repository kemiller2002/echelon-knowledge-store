# Tenant isolation

`view now session entries` returns `SessionExpired` when the session is not
active, otherwise the entries whose `TenantId` equals the session's tenant, in
their original order. No role, including `Admin`, widens this (DF-FXL-0005).

# Stored form of a new entry

An accepted entry is appended to the ledger with its description trimmed,
`Approved = false` and `ApprovedBy = None`, whatever the caller supplied.
Existing entries are unchanged and keep their order.
