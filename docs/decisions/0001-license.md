# ADR 0001 — License

- Status: accepted
- Date: 2026-11-16

## Context

The mission brief allows MIT "if consistent with the verified repository policy".
A survey of Echelon repositories on 2026-11-16 found PolyForm Noncommercial 1.0.0 in
aegis, arca, dokimos, fides, forma, mercatus, percepta, praxis and signal; MIT only in
echelon-diagnostic-framework.

## Decision

Use PolyForm Noncommercial 1.0.0 with the standard Echelon `NOTICE`, because MIT is
not consistent with the predominant repository policy. The owner can relicense later.
